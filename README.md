# Notebook Runner

A Scratch / HTML5 arcade runner game packaged as a standalone web build with TurboWarp Packager.

## Play Live

Play directly in your browser via GitHub Pages:

- **Live URL:** `https://ybk656.github.io/Notebook_Runner/`

## Run Locally

1. Clone the repository or download `index.html`.
2. Double-click `index.html` to open it in a modern web browser.

## Project Structure

- `index.html`: Standalone playable web build exported with TurboWarp Packager.
- `README.md`: Project overview and usage notes.
